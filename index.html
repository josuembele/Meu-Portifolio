Sobre mim

  • Desenvolvimento web
  • E-commerce
  • Gestão de estoque
  • Lógica de programação

Sou Josué Mbele, estudante do primeiro semestre de Engenharia de Software. Antes da faculdade, trabalhei com gestão de estoque e com o gerenciamento de contas no Mercado Livre e depois passei a prestar consultoria de e-commerce para outras empresas.

Nessa experiência, ajudei a implantar o sistema Bling, treinei equipes e participei de treinamentos na sede do Mercado Livre. Foi ali que percebi como um bom sistema facilita o trabalho de quem o usa.

Agora quero levar essa visão para o código: construir software útil, claro e confiável. Meu objetivo é crescer como desenvolvedor e criar produtos que resolvam problemas reais.
